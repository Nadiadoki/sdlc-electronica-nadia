# Aider - Semana 5, Dia 2


## Instalacion
Instale Aider correctamente (version 0.86.2) con:

```
py -m pip install aider-install
aider-install
```

Tuve que llamar al ejecutable con su ruta completa la primera vez (py -m aider_install fallo porque aider-install es un .exe, no un modulo de Python), y despues abrir una terminal nueva porque el PATH no se actualizo en la ventana ya abierta.

## Configuracion del modelo
Aider requiere una API key de pago de un proveedor externo (OpenAI, Anthropic, etc.) para conectarse a un modelo. Decidi no crear una cuenta de pago solo para este ejercicio, asi que no llegue a correr aider semana5/conversions.py con instrucciones reales.

Complete el ejercicio equivalente con Copilot Chat, como indica la guia para este caso.
